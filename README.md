# 🌵 CANGAÇO: DESTINOS DO SERTÃO

## 📖 Sobre o projeto

Cangaço: Destinos do Sertão é um jogo de RPG de aventura desenvolvido em linguagem C, ambientado no sertão nordestino.

O jogador poderá explorar diferentes regiões, conhecer personagens, participar de batalhas, coletar recursos e cumprir missões ao longo de sua jornada.

O projeto será executado no terminal e desenvolvido em equipe, utilizando os conceitos de programação estudados durante a disciplina.

## 🎯 Objetivo

Desenvolver um jogo interativo em linguagem C, colocando em prática conceitos como:

- Funções;
- Estruturas condicionais;
- Estruturas de repetição;
- Vetores e matrizes;
- Structs;
- Manipulação de dados;
- Organização e integração de arquivos.

## 🎮 Funcionalidades previstas

O jogo contará com:

- Menu principal;
- Escolha de personagens e classes;
- História com diálogos e missões;
- Mapa com exploração e movimentação;
- Sistema de batalhas;
- Inventário de itens e recursos;
- Coleta de alimentos, água e outros objetos;
- Interação com personagens;
- Progressão durante a aventura.

## 📁 Organização dos arquivos

O projeto está dividido em módulos para facilitar o desenvolvimento e permitir que cada integrante trabalhe em sua própria parte.

```text
Cangaco-Destinos-do-Sertao/
│
├── historia/
│   ├── historia.c
│   └── historia.h
│
├── inventario/
│   ├── inventario.c
│   └── inventario.h
│
├── mapa/
│   ├── mapa.c
│   └── mapa.h
│
├── personagens/
│   ├── personagem.c
│   └── personagem.h
│
├── main.c
│
└── README.md
```

### Para que servem os arquivos?

- `.c`: contém a implementação das funções e a lógica de cada parte do jogo.
- `.h`: contém as declarações das funções utilizadas pelos outros módulos.
- `main.c`: contém o menu principal e a integração das funcionalidades.
- `README.md`: apresenta informações e orientações sobre o projeto.

## 🔄 Organização do trabalho em equipe

O desenvolvimento será realizado de forma colaborativa, utilizando o GitHub e o GitHub Desktop.

Cada integrante deverá:

1. Acessar o repositório compartilhado.
2. Baixar o projeto pelo GitHub Desktop.
3. Abrir os arquivos no editor de código.
4. Desenvolver somente a parte pela qual é responsável.
5. Salvar as alterações.
6. Registrar as modificações utilizando Commit.
7. Enviar as atualizações utilizando Push origin.

Antes de começar a trabalhar, é importante atualizar o projeto para obter as alterações mais recentes dos outros integrantes.

### ⚠️ Cuidados durante o desenvolvimento

- Evitar modificar arquivos de outros integrantes sem conversar com a equipe.
- Não apagar arquivos ou pastas sem autorização.
- Manter os nomes dos arquivos e das funções organizados.
- Avisar a equipe quando uma funcionalidade estiver concluída.
- Testar as alterações antes de enviá-las.
- Conversar antes de modificar funções utilizadas por outros módulos.
